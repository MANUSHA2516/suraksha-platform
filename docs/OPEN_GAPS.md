## IMPLEMENTATION DECISIONS

- One NestJS API, one PostgreSQL schema and one staff Next.js application; React Native is USER-only. The source identity is preserved by `Case.reference`, never copied to role-specific case stores.
- NIC/phone is identification, not authentication proof. Add Argon2-protected passwords; verified staff provisioning is Admin-only. Phone/NIC possession verification is not claimed. Account age consent follows the screen's 16+ threshold; research recruitment remains distinct.
- User preferences/security/identity live in User; StaffProfile holds role-specific attributes. Clinical sessions use appointment lifecycle plus separate encrypted notes. See DATA_MODEL for every normalization decision.
- Web uses HttpOnly cookies and Origin checks; mobile stores refresh credentials in SecureStore. Access lifetime is ten minutes; refresh lifetime seven days, rotating atomically with replay revocation. “Remember device” controls persistent web refresh cookies.
- Evidence is encrypted at rest by the server using a local environment key; plaintext is processed transiently on authorized upload/download. No E2E claim. File imports cap at 25 MB, in-memory image preview at 5 MB.
- GPS is considered stale after two minutes, future readings are rejected, and foreground location requests time out. Sharing expires within two hours. Missing permission never becomes fabricated coordinates.
- Unvalidated analysis returns an explicit demo result with no confidence. Reports can be filed independently of AI availability. Manual moderation holds posts/comments pending review.
- Legal publication requires reviewed content and source metadata. No incomplete legal quotation or bibliography entry becomes a published legal answer automatically.
- English strings preserve the available design; si/ta selection currently declares fallback rather than pretending translation verification.
- SSE is a local realtime implementation backed by PostgreSQL OutboxEvent; Redis is available for a future distributed worker rather than an artificial dependency.
- Additional empty/error/403/404 states and supporting forms are engineering necessities; they do not add to or reduce the 47 documented screen count.

Local functionality and test evidence are described in README.md and VERIFICATION.md. These explicit gaps mean the project is a runnable research prototype, not a completed production safety service.
